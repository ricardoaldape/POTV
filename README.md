# POTV

POTV is a local-first media client for Android and Android TV.

The client handles Live TV, Sports Hub, playback, sources, playlists, credentials and viewing state locally on the device. POTV infrastructure is reserved for accounts, subscriptions, device entitlements, releases and privacy-preserving product analytics.

## Priorities

1. Core Android + Android TV experience
2. Live TV + EPG
3. Sports Hub
4. Multi-backend player (native + isolated WebView)
5. Local phone-to-TV sync
6. POTV Control
7. Stremio, Nuvio and progressive Kodi compatibility

## Development

This repository is proprietary/private. It is a clean-room implementation and does not copy LolPlusTV source code.

Run `tool/bootstrap_android.sh` once on a development machine with Flutter installed to generate Android platform files.
