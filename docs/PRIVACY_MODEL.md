# POTV Privacy Model

Stored locally:
- source and addon configuration
- M3U/XMLTV endpoints and credentials
- favorites, history and playback progress
- source cookies/tokens
- playback preferences

Allowed on POTV Control:
- account and subscription entitlement
- authorized device records
- app version
- coarse product events such as app_open
- sanitized crash diagnostics

Forbidden in telemetry:
- stream URLs
- watched titles or channels
- playlist contents
- source credentials/cookies
- addon URLs
