# POTV Security Principles

1. No audiovisual proxying through POTV infrastructure.
2. Source secrets stay local.
3. Web playback is isolated; unsolicited external navigation and device permissions are denied by default.
4. Third-party executable plugins must run in a sandbox with explicit capabilities.
5. Telemetry is scrubbed before transmission.
6. APK releases must be signed and update metadata must include integrity verification.
